# jerteoy.github.io

Website of Jerte Oy, published with GitHub Pages at https://jerteoy.github.io/.

- `index.html` – front page
- `privacy.html` – Passikuva privacy policy (https://jerteoy.github.io/privacy.html), the URL
  given to the app stores. It is a copy of `www/privacy.html` in the Passikuva repository;
  copy it again whenever the policy changes, so the app and the website stay identical.
- `icon.svg` – Passikuva icon
